## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The post itself is the entry: `POST.json` names the X post, and `main.ts` (Node 22, standard library only) copies `POST.json` to the output directory for the gate to read.
